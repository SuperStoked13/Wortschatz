# Silbentrennung (Hyphenator.cs)

TeX-Trennmuster aus **hyph-utf8** (https://github.com/hyphenation/tex-hyphen, Ordner
`hyph-utf8/tex/generic/hyph-utf8/patterns/txt/`), unverändert, geholt am 06.11.2026. Gebraucht nur, wenn ein Wort
breiter ist als seine Zeile (Handy: Karteikarten, Lernen, Schreiben); dann wird es nach Silben mit «-» getrennt statt
irgendwo mitten im Wort.
