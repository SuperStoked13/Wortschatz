Was der Server verarbeitet

Bei jedem Aufruf erhält der Server deine IP-Adresse, die aufgerufene Adresse, die Uhrzeit und die Angaben deines Browsers, die bei jeder Anfrage mitgehen. Damit wird die Seite ausgeliefert und vor Missbrauch geschützt:

  • Der Server zählt, wie viele Anfragen und Daten von einer Adresse kommen, und bremst Adressen vorübergehend, die die Website überlasten. Diese Zähler liegen nur im Arbeitsspeicher, kommen nie auf die Festplatte und verschwinden nach spätestens zwei Tagen.
  • Im Protokoll des Servers steht deine IP-Adresse nur gekürzt (zum Beispiel 203.0.113.0), sodass sie nicht mehr auf einen einzelnen Anschluss zeigt. Das Protokoll dient der Fehlersuche und wird regelmässig gelöscht.
    • {{#downloads.local}}
  • Für Downloads zählt der Server, wie oft jede Version pro Tag geladen wurde. Diese Zahl enthält nichts über die Personen, die geladen haben.
    • {{/downloads.local}} {{#site.login}}
  • Die Website ist passwortgeschützt. Nach der Anmeldung speichert dein Browser ein Cookie, damit du das Passwort nicht bei jedem Aufruf eingeben musst. Es enthält nur sein Ablaufdatum und eine Prüfsumme, nichts über dich, und läuft nach {{site.loginDays}} Tagen ab.
    • {{/site.login}}

Verschlüsselung und Name

Die Verbindung ist mit HTTPS verschlüsselt (Zertifikat von Let’s Encrypt). Der Name wortschatz.duckdns.org wird über den Dienst DuckDNS auf diesen Server geleitet. DuckDNS sieht dabei nur, welche Adresse der Server hat, aber nicht, wer die Website besucht. Wer die Seite über die Ausweichadresse bei Cloudflare öffnet (zum Beispiel in einem Netz, das DuckDNS sperrt): Dort endet die Verschlüsselung, und Cloudflare leitet die Anfragen an diesen Server weiter. Cloudflare kann dabei alles sehen, was über diese Adresse läuft: die Internetadresse, die aufgerufenen Seiten und die Download-Links{{#site.login}}, auch das Passwort und das Anmelde-Cookie{{/site.login}}.
