Was der Server verarbeitet

Bei jedem Aufruf erhält der Server deine IP-Adresse, die aufgerufene Adresse, die Uhrzeit und die Angaben deines Browsers, die bei jeder Anfrage mitgehen. Damit wird die Seite ausgeliefert und vor Missbrauch geschützt:

  • Der Server zählt, wie viele Anfragen und Downloads von einer Adresse kommen, und sperrt Adressen vorübergehend, die die Website angreifen oder überlasten. Diese Zähler liegen nur im Arbeitsspeicher, kommen nie auf die Festplatte und verschwinden nach spätestens zwei Tagen.
  • Im Protokoll des Servers steht deine IP-Adresse nur gekürzt (zum Beispiel 203.0.113.0), sodass sie nicht mehr auf einen einzelnen Anschluss zeigt. Das Protokoll dient der Fehlersuche und wird regelmässig gelöscht.
  • Für Downloads zählt der Server, wie oft jede Version pro Tag geladen wurde. Diese Zahl enthält nichts über die Personen, die geladen haben.

Verschlüsselung und Name

Die Verbindung ist mit HTTPS verschlüsselt (Zertifikat von Let’s Encrypt). Der Name wortschatz.duckdns.org wird über den Dienst DuckDNS auf diesen Server geleitet. DuckDNS sieht dabei nur, welche Adresse der Server hat, aber nicht, wer die Website besucht.

Die App

Wortschatz selbst sendet keine Daten. Lernsets, Fortschritt und Einstellungen bleiben auf deinem Computer: in der Mac-App in ihrem eigenen Ordner, in der Windows-App unter %LOCALAPPDATA%\Wortschatz. In der Windows-App lädt der erste Import eines PDFs oder Fotos zwei Programmbibliotheken von cdn.jsdelivr.net nach, alles andere funktioniert ohne Internet.
