New words come up as multiple choice first; next time, you type them. Get a word right twice in a row and you’ve mastered it.

You see a word and type the translation. If only the article or the pronoun is missing, the answer still counts. Accents are one click away.

Flip with the space bar, sort with the arrow keys. Whatever you’re still learning comes back in the next round.

All questions on one sheet, with a time limit if you like. Small mistakes cost half a point, and at the end you get a Swiss grade from 1 to 6 (6 is best).

Paste a list, drop in a file or take a photo of a vocabulary page. Wortschatz works out which part is the word and which is the translation.

First launch on a Mac
  1. Open the downloaded file and drag Wortschatz into the Applications folder.
  2. Open Wortschatz. macOS says that Apple could not verify that Wortschatz is free of malware. Click “Done”, not “Move to Trash”.
  3. Open Privacy & Security in System Settings and scroll down to “Security”. Next to ““Wortschatz” was blocked to protect your Mac”, click “Open Anyway”, click it again in the next window, and confirm with your password or Touch ID.

You only need to do this the first time. The “Open Anyway” button only appears after you’ve tried to open the app, and it stays for about an hour. Wortschatz isn’t notarized by Apple because that requires a paid developer account. The app runs in the macOS sandbox{{^macUpdates}} and doesn’t need internet access{{/macUpdates}}{{#macUpdates}}; it only goes online to ask GitHub for new versions, which it then installs by itself, without these steps{{/macUpdates}}.

It’s quicker in Terminal: instead of steps 2 and 3, paste this command and press Return. It unblocks Wortschatz and opens the app.

Mac, in Terminal xattr -dr com.apple.quarantine /Applications/Wortschatz.app && open /Applications/Wortschatz.app
First launch on Windows
  1. If your browser warns while downloading that the file isn’t commonly downloaded, choose “Keep”.
  2. Put the downloaded file somewhere permanent, for example on the desktop, and double-click it.
  3. If “Windows protected your PC” appears, click “More info” and then “Run anyway”.

If Smart App Control in Windows 11 blocks the app, there’s no exception for it: Wortschatz only starts once it’s turned off under “Windows Security”, “App & browser control”. It protects against unknown programs; whether you turn it off is up to you.

The warnings appear because Wortschatz isn’t signed with a paid certificate. Wortschatz needs nothing else: the file contains everything. Your study sets live in the folder %LOCALAPPDATA%\Wortschatz and stay when you replace the file with a newer one.{{#windowsUpdates}} Wortschatz gets new versions by itself: about once a day it asks GitHub and replaces the file when you quit the app – without these steps.{{/windowsUpdates}} On first launch, Wortschatz takes over everything from the previous Windows app (up to version 1.1) and then removes it; a backup of its study sets stays in the same folder.
