What the server processes

With every visit, the server receives your IP address, the address you asked for, the time and the details your browser sends along with every request. They are used to deliver the site and protect it from abuse:

  • The server counts how many requests and how much data come from one address, and briefly slows down addresses that overload the website. These counters live only in memory, never reach the disk and disappear after two days at most.
  • The server’s log shows your IP address only shortened (for example 203.0.113.0), so it no longer points to a single connection. The log is used for troubleshooting and deleted regularly.
    • {{#downloads.local}}
  • For downloads, the server counts how often each version was downloaded per day. This number says nothing about the people who downloaded it.
    • {{/downloads.local}} {{#site.login}}
  • The website is password protected. After you sign in, your browser stores a cookie so you don’t have to enter the password on every visit. It contains only its expiry date and a checksum, nothing about you, and expires after {{site.loginDays}} days.
    • {{/site.login}}

Encryption and name

The connection is encrypted with HTTPS (certificate from Let’s Encrypt). The name wortschatz.duckdns.org is pointed at this server by the DuckDNS service. DuckDNS only sees which address the server has, not who visits the website. If you open the site through the fallback address at Cloudflare (for example on a network that blocks DuckDNS), the encryption ends there and Cloudflare forwards the requests to this server. Cloudflare can see everything that goes through that address: the internet address, the pages you open and the download links{{#site.login}}, including the password and the sign-in cookie{{/site.login}}.

Language

The website is available in German and English. Which one you see depends on your browser’s language settings. If you pick one yourself (DE or EN at the top of the page), your browser remembers your choice in its local storage. It stays on your device and is never sent to the server.

The apps are hosted on GitHub (github.com), a service of GitHub, Inc., a subsidiary of Microsoft. Clicking the download button takes you straight there, and GitHub sends you the file. GitHub receives your IP address and the details your browser sends along, and GitHub’s privacy terms apply. This website loads nothing from GitHub and passes no data to GitHub.
